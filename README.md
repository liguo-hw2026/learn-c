## Day 1 ｜ 开工奠基 + 开发环境 + 第一个 C 程序

**完成内容**

- 安装并配置 Git（2.56.0.windows.2），设置 `user.name` / `user.email`
- 确认 VS2022「使用 C++ 的桌面开发」工作负载（MSVC v143 + Windows 11 SDK）
- 新建空项目，源文件 `main.c`（扩展名 `.c`，按 C 语言编译，非默认 `.cpp`）
- 理解编译-链接-运行四步；`main` 函数结构；`printf` 格式化输出
- 跑通第一个程序：hello world
- 学会 Git 本地流程：`init → add → commit`
