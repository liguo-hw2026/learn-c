# 进制转换速查表

> 硬件工程师每日基本功。四种进制：二进制(B,基2) / 八进制(O,基8) / 十进制(D,基10) / 十六进制(H,基16)。
> 转换核心：除基取余法（→R 进制）、按权展开（→十进制）、二进制↔十六进制 4 位分组（秒换）。

## 1. 四种进制对照

| 进制 | 基 | 数字 | C 语言前缀 | 硬件用途 |
|---|---|---|---|---|
| 二进制 | 2 | 0–1 | `0b1010`（部分编译器支持） | 看每一位 bit |
| 八进制 | 8 | 0–7 | `010`（前导 0！） | chmod 权限，硬件里少用 |
| 十进制 | 10 | 0–9 | `10` | 给人看 |
| 十六进制 | 16 | 0–9, a–f | `0x1A` | **寄存器 / 地址 / 内存主力** |

## 2. 二进制 ↔ 十六进制（最重要，练到秒换）

每 4 位二进制 = 1 位十六进制：

| 二进制 | 十六进制 | | 二进制 | 十六进制 |
|---|---|---|---|---|
| 0000 | 0 | | 1000 | 8 |
| 0001 | 1 | | 1001 | 9 |
| 0010 | 2 | | 1010 | A |
| 0011 | 3 | | 1011 | B |
| 0100 | 4 | | 1100 | C |
| 0101 | 5 | | 1101 | D |
| 0110 | 6 | | 1110 | E |
| 0111 | 7 | | 1111 | F |

- `0xAD` → `1010 1101`
- `0xFF` → `1111 1111`（8 个 1，全置位）
- `0x64` → `0110 0100`

## 3. 二进制 ↔ 八进制（每 3 位一组）

- `101 110` → `056`

## 4. 十进制 → R 进制（除基取余，从下往上读）

例：29 → 二进制
```
29 ÷ 2 = 14 余 1
14 ÷ 2 =  7 余 0
 7 ÷ 2 =  3 余 1
 3 ÷ 2 =  1 余 1
 1 ÷ 2 =  0 余 1   ← 从下往上读：11101
```

例：255 → 十六进制
```
255 ÷ 16 = 15 余 15(F)
 15 ÷ 16 =  0 余 15(F)  ← 从下往上：FF
```

## 5. R 进制 → 十进制（按权展开）

- `0b11101` = 1×16 + 1×8 + 1×4 + 0×2 + 1×1 = **29**
- `0x1A`   = 1×16 + 10        = **26**
- `0xD6`   = 13×16 + 6        = **214**

## 6. 十进制 → 十六进制 走「二进制中桥」（更稳，避免除 16 余数出错）

```
100 → 二进制 1100100
分组:  0110 0100 → 6 4 → 0x64
```

## 7. ⚠️ 八进制前导 0 陷阱

`int y = 010;` 里前导 0 让编译器当成八进制，`010` = 8，不是 10！新手常踩的隐性 bug。

## 8. 硬件真实用法（寄存器位操作）

STM32 的 RCC 时钟控制寄存器基址 `0x40021000`，把第 3 位置 1：
```c
volatile uint32_t *RCC = (uint32_t *)0x40021000;
*RCC |= (1 << 3);     // 1 左移 3 位 = 0b1000 = 0x8，按位或上去
```
脑子要立刻知道：`1 << 3` = 第 4 个 bit = 二进制 `1000` = 十六进制 `8`。

## 9. C 语言打印

```c
int x = 255;
printf("dec=%d hex=%x oct=%o\n", x, x, x);  // 输出 dec=255 hex=ff oct=377
// 注意：C 没有 %b，二进制要自己写函数或用计算器
```
